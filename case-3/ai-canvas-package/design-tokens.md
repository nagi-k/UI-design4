## 字体系统

### 字体栈
- 标题英文：`Unbounded, Montserrat, Arial Black, sans-serif`
- 正文中文：`PingFang SC, HarmonyOS Sans SC, Microsoft YaHei, -apple-system, sans-serif`
- 诗歌/盲盒：`Noto Serif SC, Source Han Serif SC, STSong, SimSun, serif`

### 字号
| 级别 | 尺寸 | 用途 |
|------|------|------|
| display | 26–32px | 页面大标题 |

| h2 | 15–18px | 区块标题 |
| body | 13–14px | 正文、描述 |

## 间距系统

以 4px 为基准单位：
- xs: 4px
- sm: 8px
- md: 12px
- base: 16px
- lg: 24px
- xl: 32px

页面内边距：左右 18px，底部 118px（为 Tab 栏留白）

## 阴影与光效

- 主按钮阴影：`0 10px 34px rgba(139,92,246,.4)`
- 悬浮卡片阴影：`0 20px 60px rgba(139,92,246,.18)`
- 手机外框阴影：`0 30px 80px rgba(0,0,0,.6), 0 0 60px rgba(139,92,246,.12)`
- 文字发光：`text-shadow: 0 0 22px #8B5CF666`
- 极光背景：大半径模糊径向渐变 + 缓慢漂移动画

## 动效曲线

| 场景 | 曲线 | 时长 |
|------|------|------|
| 页面转场 | `cubic-bezier(.22,1,.36,1)` | 300ms |
| 奖励/弹性 | `cubic-bezier(.34,1.56,.64,1)` | 400–600ms |
| 呼吸浮动 | `ease-in-out` | 2.8–8s |
| 粒子漂移 | `linear` | 连续 |

## 核心组件规范

### 主按钮
- 背景：极光紫到星云粉渐变 `linear-gradient(90deg, #8B5CF6, #EC4899)`
- 圆角：999px（胶囊）
- 文字：白色 14px
- 阴影：紫色发光

### 次按钮 / 玻璃按钮
- 背景：`rgba(255,255,255,.05)`
- 边框：`1px solid rgba(255,255,255,.1)`
- 圆角：16–20px
- 文字：月光白

### 卡片
- 背景：玻璃拟态
- 圆角：20px
- 内边距：16–20px
- 悬浮：轻微上移 + 边框变紫 + 阴影加深

### 情绪标签
- 圆角：999px
- 边框：情绪色 50% 透明度
- 文字：情绪色
- 内边距：6px 12px

### Tab 栏
- 底部固定
- 背景：半透明深色 + 模糊
- 5 个 Tab：首页、记录、分析、社区、我的
- 选中态：文字变白 + 顶部短横线渐变指示器

### 悬浮按钮（梦境盲盒）
- 位置：右上角
- 背景：金色到粉色半透明渐变
- 边框：金色半透明
- 动画：轻微晃动
